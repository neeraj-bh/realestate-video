# SunTec Real Estate Image to Video

Downloads for the **SunTec Real Estate Image to Video** desktop app, which turns property photos into short video clips (camera moves, drone shots, gentle motion) with Higgsfield AI, then lets you review, approve and export them. This repository holds only the installers; there is no source code here.

## Opening it the first time

The app isn't signed yet, so your computer asks once:

- **Mac:** open the `.dmg` and drag **SunTec Real Estate Image to Video** into **Applications**, then open it. When macOS says it can't check the app, open **System Settings › Privacy & Security**, scroll down and click **Open Anyway**.
- **Windows:** open the setup. If "Windows protected your PC" appears, click **More info › Run anyway**. It installs for you only and needs no admin rights.

Sign in with the name and PIN your SunTec admin gave you. On Windows, use JPG or PNG photos (HEIC and TIFF can only be converted on a Mac).

After that it opens like any other app. It checks for new versions when it opens (and from Help › Check for Updates…) and updates itself. Your photos and clips stay on your computer; only the photos you turn into clips go to Higgsfield.

Every release includes `checksums.txt` (SHA-256) for its files.
